## Featured Projects

### 🎙️ CrossIndexRAG Voice Agent

A voice-interfaced conversational AI system built on top of CrossIndexRAG.

The system allows users to ask questions through voice and receive grounded spoken responses.

**Key Features**

- Speech-to-text using Groq Whisper
- Reasoning using Gemini
- Text-to-speech using ElevenLabs
- Live microphone input
- Custom energy-threshold Voice Activity Detection
- Barge-in handling for natural interruption
- Per-stage latency instrumentation
- Grounded responses through the CrossIndexRAG pipeline

**Repository:**  
https://github.com/Eshal-ven/crossindexrag-voice-agent
